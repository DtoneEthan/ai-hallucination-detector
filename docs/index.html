它能检测什么

四个检测模块协同工作，离线即可运行大部分分析，联网可进一步核验。

🔍

声明提取

从文本中提取数字、引用、日期与技术断言，并为每条声明评估「可验证性」。

🧠

模式分析

识别过度对冲 / 过度自信、填充套话、内部矛盾、超精确数字与疑似虚构的技术实体。

🔗

URL / 引用验证

检查 DNS 解析、404 死链、可疑域名，以及伪造的 DOI / arXiv 引用。

🌐

联网事实核查

通过搜索引擎查询交叉验证提取出的声明（需联网模式）。

快速开始

用 pip 安装，或用 Python API 嵌入你自己的流程。

# 安装
pip install -e .

# CLI：检测一个文件（离线模式，无需联网）
hallucination-detector detect article.txt --offline --format json -o report.json

# 直接检测一段文本
hallucination-detector detect --text "Some AI-generated text..." --offline

# 交互模式
hallucination-detector interactive
# Python API
from hallucination_detector import HallucinationDetector

detector = HallucinationDetector(verify_online=False)
result = detector.analyze(text)

print(result.summary())          # 文本摘要
print(result.risk_score)        # 0–100 风险分
print(result.risk_level)        # LOW / MODERATE / HIGH / CRITICAL
